# Navier-stokes-namit
This project implements a 2D lid-driven cavity simulation that numerically solves the Navier–Stokes equations for incompressible flow using a vorticity–stream function formulation.
It allows real-time visualization of fluid flow within a square cavity, optionally containing a rectangular or circular obstacle.
A Streamlit-based interface enables users to interactively adjust parameters such as:
Reynolds number
Lid (top wall) speed
Number of simulation steps
Obstacle shape, size, and position

The significance of this research lies in its potential applications across various fields including heat transfer enhancement, mixing processes, and biomechanics.For instance, in heat transfer applications, the presence of obstacles can enhance thermal performance by promoting turbulence and increasing surface area for heat exchange. Similarly, in biomedical engineering, understanding the flow of blood around obstructions or through narrow vessels is essential for developing effective treatments and diagnostic tools.\\
The computational framework developed in this project can serve as a valuable tool for researchers and engineers to explore and optimize designs involving confined fluid flow with obstacles or obstructions, ultimately leading to improved system performance, energy efficiency, and operational safety.
